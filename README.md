通过**vibe coding**构建的一个面向来南京青年的租房片区智能推荐和评估平台v1.0
整体平台网页分为3个页面:登录页（普通用户，管理员登录）、片区推荐页面、片区通勤和生活圈设施评估(含租住适配得分）页面
使用CSS JS python搭建，数据库连接了supabase

**普通用户登录**
注册账号——登录——输入工作地址，通勤偏好——平台调用扣子工作流智能推荐最符合用户租住需求的四个片区（未接入真实token_key，会显示预置结果）——点击任何一个感兴趣的片区——
显示片区的租住适配总分，通勤分项得分，生活圈设施得分（通过后台函数计算）—— 显示片区到工作地的车行路线和公共交通路线——显示候选片区的生活圈设施雷达评分图和最近的设施
分布情况（未接入高德API_key的情况下无准确显示）——点击存储，可将评估结果存储至数据库中。
**管理员登录**
点击管理员登录——查看数据看板（各项服务使用量，使用的日变化情况，被推荐最多的片区等信息）

如需要使用完整功能，需要在run_bat配置对应的扣子令牌，以及高德对应服务的API_key信息，才能正常使用
**使用到了扣子工作流，高德的网页交互地图、地址解析、范围搜索、POI查找、路线规划等API**来实现部分功能。
