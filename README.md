**宁安居——一个为来南京青年打造的租房区域智能推荐平台。**
初到南京不知道住哪里合适？租房平台房源太多无从下手？您现在可以把这个困难交给我们，在宁安居，体验一站式租房社区推荐的省心体验。
注册并登录我们的平台以后，你就也可以输入你的租房需求（你的工作地点、租金预算、上下班通勤要求、周边需要什么样的设施、想租什么样的房子等等），我们的系统会收集您的需求，通过后台的推荐算法工作流为您推荐“通勤优先”、“性价比优先”、“平衡”三种类型的租住社区推荐方案，满足您不同的租住需求。高亮显示的社区就是满足您对居住地所有额外设施要求的社区。您可以点击各选项卡中的查看详情，进入详情查看页面，您可以直观地看到您所关注的社区和您输入的租房需求的匹配程度，如何从您选择的社区到上班地点的通勤路线、以及您所选择社区周边的生活设施情况。我们在详情页还设置了贝壳、自如、安居客等主流租房平台的链接入口，方便您直接根据我们推荐的社区进行具体房源的搜索。如果您对推荐的社区感兴趣，还可以点击存储，并在“个人信息”页面进行多次查看。通过左侧的个人信息页可以查看并维护您的租房需求，以及查看您历史保存的社区推荐结果。宁安居，做您来南京租房第一站的小助手！

**v2.0版更新内容**
本次更新升级完善了登录页面、租房社区推荐界面的展示效果。现在你可以在侧边栏方便地切换页面。新增上线了“个人信息”页面，在这里回顾个人的租房偏好和收藏社区的记录变得方便。重新设计了租房需求及偏好的收集表，现在你可以选择更多的偏好与需求了！

完全重构了社区推荐流程——我们首先用5分钟可达的距离将南京划分为若干个微社区单元，然后根据南京15分钟生活圈设施配置标准，对微社区进行了筛选，选择满足设施覆盖条件的社区作为备选。当您点击生成推荐按钮时，后台会根据您输入的工作地址、租金预算、通勤距离以及社区本身的设施覆盖状况在微社区备选数据库中优先进行筛选。如果您还有其他设施的需求，我们也设计了查找模块，能够尽可能满足您对于额外生活设施的要求。我们会给您推荐“通勤优先”、“性价比优先”、“平衡”三种类型的租住社区推荐方案，满足您不同的租住需求。

在点击详情查看后，您可以直观看到该社区的租住适配得分状况，从这个社区出发到上班地点的通勤路线，以及该社区周边常见的一些生活设施的配备情况。您如果觉得这个社区是您满意的租住地，可以直接点击我们为您提供的链接，在主流租房平台按我们的社区进行搜索。这样您找房就更有目的性，为您节省在海量房源中寻找的麻烦。您还可以将需要反复查看的社区存储到数据库中，在我的信息页反复查看哦。

我们还设置了管理员登录入口，管理员通过登录账号，可以看到后台的API调用次数，推荐次数，日活用户趋势，以及哪些片区被经常推荐。方便网站的后期运营与管理。
